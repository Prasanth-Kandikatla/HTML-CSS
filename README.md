# 🔘 Custom HTML & CSS Buttons

This project showcases a collection of buttons built using only HTML and CSS. Each button features different styles, hover effects, and responsive design — perfect for forms, websites, or UI inspiration.

## 🚀 Live Demo

[Click here to see it live!](https://html-css-practice-buttons-beginner.netlify.app/)

## 📁 Features

- Pure HTML & CSS (no JavaScript)
- Hover animations
- Different styles: flat, 3D, outline, and gradient
- Mobile-responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
